# 🏗️ Engineering Approach

I believe good software is not only about making the feature work.

I focus on:

```text
Clean Code
   +
Scalable Architecture
   +
Reusable Components
   +
Performance
   +
Security
   +
Maintainability
   +
Good Developer Experience
```

### 🔹 Principles I Follow

* Build reusable components
* Keep business logic separated from UI
* Prefer strongly typed APIs
* Write maintainable TypeScript
* Avoid unnecessary re-renders
* Design for scalability
* Handle loading/error/empty states properly
* Keep API and state-management logic organized
* Optimize before production issues become expensive
* Keep code easy for other developers to understand
